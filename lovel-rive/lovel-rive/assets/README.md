# Assets

## images/lavori/
Foto del portfolio. Consigliato: ratio 3:4 (verticale), JPG ottimizzato, almeno 600×800px.
Naming consigliato: `lavoro-01.jpg`, `lavoro-02.jpg`, ecc.

## images/hero/
Eventuale immagine di sfondo per hero section (opzionale).

## images/logo/
Logo Lovel. Formato consigliato: SVG (per scalabilità) o PNG con trasparenza.
- `logo.svg` — logo principale
- `favicon.ico` — favicon (32×32)
